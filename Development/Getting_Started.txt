Prerequisites

- X-Studio: https://forum.egosoft.com/viewtopic.php?t=301433

- Custom.Syntax.txt (comes with the GitHub repo)
  - This is needed as it contains the custom X3AP script commands that the entire mod uses.


Optional

- AstroGrep: https://astrogrep.sourceforge.net/
  - This program is HIGHLY recommended, as it lets you search for script names and keywords.

- MSCI Handbook: https://www.egosoft.com/download/x2/bonus_en.php?download=97)
  - Even though this handbook is from X2: The Threat, the commands are still used today. 
  - Whlie X-Studio may contain a summary of each command, the details and useful information not summarized in X-Studio are in this PDF.
  - Most commands in X-Studio have a reference in the forum. Right-click a command and click "View MSCI Reference" to see its corresponding entry in the forum.


Installation Instructions

1. Download X-Studio and install it somewhere. Note: for this project, the original X-Studio is good enough.

2. Download the Custom.Syntax.txt file from the Add-Ons repo. Put this in your X-Studio folder.

3. Start X-Studio. You will need to configure it accordingly. Set up your preferences in View -> Application Preferences.

4. Go to Game Data and set your X3 root folder. X-Studio should automatically locate your scripts folder. If you did it correctly, you will see the X3AP logo and a green checkmark.

5. You should be all set from this point on.
